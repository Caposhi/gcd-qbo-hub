# Documentation archive

Everything in this directory is **historical only and not operational guidance**. It may describe incomplete phases, superseded routes, old architecture, temporary findings, or external state that was true only at the time. Use current source, the root README, and current `docs/` runbooks for decisions.

Archived records:

- `PROGRESS.md` — accumulated implementation progress log.
- `PROGRESS_tekmetric.md` — Tekmetric workstream progress snapshot.
- `HUB_HANDOFF.md` — superseded hub handoff.
- `HANDOFF_APPEND_parallel_workstreams.md` — superseded parallel-work note.

Historical documents were retained for provenance and sanitized where necessary. They must never contain credentials, production personal data, raw customer examples, or secret values.
